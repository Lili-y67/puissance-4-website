API Bot

Un compte non lie Discord peut etre transforme en bot. Le programme externe ping, rejoint la file bot, lit la grille, puis envoie ses coups.

POST /api/players/:id/convert-bot
Authorization: Bearer p4bot_xxx
POST /api/bot/queue/join
GET /api/bot/game
POST /api/bot/move
POST /api/bot/challenge/:id
