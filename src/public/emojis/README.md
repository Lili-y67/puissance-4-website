# Pack d'emojis Puissance 4 pour Discord

Les fichiers PNG sont en 128 x 128 px avec transparence et les GIF sont optimises pour l'import Discord.

Noms conseilles : `p4_gg`, `p4_win`, `p4_lose`, `p4_draw`, `p4_drop`, `p4_connect4`, `p4_think`, `p4_rage`, `p4_laugh`, `p4_love`, `p4_shock`, `p4_sleep`, `p4_clutch`, `p4_block`, `p4_rematch`, `p4_lucky`, `p4_oops`, `p4_salute`, `p4_party`, `p4_trophy`, `p4_lili_love`, `p4_lili_cheer`.

Le sous-dossier `sources/` conserve les rendus chroma-key en haute definition. Les PNG a la racine sont les versions finales pretes a televerser.
